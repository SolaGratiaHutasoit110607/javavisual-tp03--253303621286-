
# Character Manager — TP3 (Java Visual SIH-6406)

## Deskripsi
Character Manager adalah program Java untuk mengelola data karakter permainan. Program ini menerapkan konsep OOP, enum, constructor, encapsulation, level up, mana, dan pengecekan status hidup karakter.

## Fitur
- Menampilkan tiga karakter: Odette, Angela, dan Layla.
- Menampilkan informasi karakter menggunakan `toString()`.
- Melakukan simulasi level up.
- Mengatur mana dengan validasi nilai negatif.
- Memeriksa status hidup menggunakan `isAlive()`.
